# Cybersecurity_Project

CodeAlpha CyberSecurity Internship 

This repository contains the practical cybersecurity tasks I completed during my CodeAlpha Security Internship.

The project provided hands-on experience with cybersecurity concepts, network security, security awareness, intrusion detection, and security monitoring.

## Tasks Completed

### Task 1 - Basic Network Sniffer

Developed a basic network sniffer using python to capture and analyze network packets.

**Skills demonstrated:**
- Python programming
- Network packet analysis
- Network protocols
- Traffic monitoring
- Basic cybersecurity analysis

### Task 2 -Phishing Awareness

Created a phishing awareness training webpage designed to educate users about phishing attacks and how to identify suspicious emails, links, and websites.

**Skills demonstrated:**
- Phishing awareness
- Social engineering awareness
- HTML
- Cybersecurity education
- Security best practices

### Task 4 - Network Intrusion Detection

Configured and tested a Network Intrusion Detection System using suricata and Wazuh.

Suricata was used to monitor network traffic and detect suspicious activity,while Wazuh was used for security monitoring and agent management.

**Skills demonstrated:**
- Network intrusion detection
- Suricata IDS
- Wazuh
- Security event monitoring
- Linux administration
- Network traffic analysis

## Tools & Technologies

- Ubuntu

## Key Learning Outcomes

Through these tasks, I gained pratical experience in network monitoring, packet analysis, phishing awareness, intrusion detection, security event monitoring, and Linux-based cybersecurity tools.

The Internship also strengthened my ability to troubleshoot technical issues, document security activities, analyze results, and present practical cybersecurity work.
