# Task 2: Phishing Awareness Traning

## Project Overview

This project is an interactive phishing awareness training module designed to educate users about phishing attacks and common social engineering techniques.

The module explains how phishing emails and fake websites can be identified , provides practical tips for avoiding phishing attacks, and includes examples and an interactive quiz to improve security awareness.

## Objective

The objective of this project is to improve users' ability to recognize phishing attempts, identify common warning signs, and apply safe cybersecurity practices when using email and the internet.

## Topics Covered

- What is phishing?
- How phishing attacks work
- How to recognize phishing emails
- How to identify fake websites
- Common social engineering tactics
- Real-world phishing examples
- Best practices for avoiding phishing
- Interactive phishing awareness quiz

## How to Recognize Phishing Emails

Common warning signs include:

- Suspicious or unfamiliar sender addresses
- Urgent or threatening language
- Unexpected attachments
- Request for passwords or sensitive information]
- Suspicious links
- Spelling and grammatical errors
- Messages that create unnecessary fear or pressure

## How to Identify Fake Websites

Users should check:

- The website address and domain name
- Whether the connection uses HTTPS
- Unexpected redirects
- Suspicious spelling or unusual domain names
- Request for sensitive information
- Poorly designed or copied website content

HTTPS alone does not guarantee that a website is legitimate, so the domain name and context should also be checked carefully.

## Social Engineering Tactics

Attackers may use psychological techniques to manipulate victims. Common examples include:

- Urgency
- Fear
- Authority
- Curiosity
- Trust
- Financial incentives

These techniques are designed to make victims act quickly without properly verifying the request.

## Best Practices

To reduce the risk of phishing:

1. Verify unexpected request before responding.
2. Do not click suspicious links.
3. Check the sender's email address carefully.
4. Avoid opening unexpected attachments.
5. Use multi-factor authentication where available.
6. Never share passwords or sensitive information.
7. Report suspicious messages to the appropriate security team or service provider.
8. Keep software and browsers updated.

## Real-World Example

A common phishing scenario is an email claiming that a user's account will be suspended unless they immediately click a link and verify their information.

Warning signs may include:

- An unexpected account warning
- Urgent language
- A suspiciouss sender address
- A link that does not belong to the legitimate organization
- A request for sensitive information

The safest approach is to avoid clicking the link and independently visit the organization's offical website or contact the organization through a trusted channel.

## Interactive Quiz

The training module includes an interactive quiz that tests the user's ability to:

- Identify phishing emails
- Recognize suspicious links
- Identify social engineering tactics
- Apply safe cybersecurity practices
